# customer-intelligence-prediction
# 📊 End-to-End Customer Intelligence & Predictive Analytics Platform

An integrated Data Science and Machine Learning project leveraging real-world Mall Customer datasets to perform Unsupervised Customer Segmentation, High-Precision Churn Classification, and Future Spend Forecasting.

## 🌟 Key Machine Learning Modules
1. **Customer Segmentation (Unsupervised Learning):** Grouped retail shoppers into 5 behavior-driven clusters using **K-Means Clustering** based on income and spending dynamics.
2. **Customer Churn Prediction (Supervised Classification):** Implemented a **Random Forest Classifier** achieving high precision in detecting potential user churn.
3. **Future Spend Forecasting (Supervised Regression):** Built a **Random Forest Regressor** to accurately estimate customer lifetime spending value.

## 🛠️ Tech Stack & Libraries
- **Language:** Python
- **Environment:** Google Colab
- **Libraries:** Pandas, NumPy, Scikit-Learn, Seaborn, Matplotlib

## 📈 Evaluation Metrics
- **Segmentation:** Silhouette Coefficient
- **Classification:** Accuracy, Precision, Recall, F1-Score
- **Regression:** $R^2$ Score, RMSE
